# 光影绘梦师 · The Dream Painter

一个关于颜色、风与画笔的短篇平台解谜游戏。

> 世界遗忘了颜色。你有一支笔，和一颗还记得颜色的心。

## 在线游玩

- **GitHub Pages**：https://sjsjxn46xqps.github.io/light-shadow-painter/
- **jsDelivr 镜像**（CDN 加速）：https://cdn.jsdelivr.net/gh/sjsjxn46xqps/light-shadow-painter@v1.0.0/index.html

建议使用桌面版 Chrome / Edge，配合鼠标与键盘游玩。游戏无外部依赖，也可以直接双击 `index.html` 离线游玩。

## 玩法

你是手持「光影笔」的小画家。黑白灰的世界里，只有你画下的笔迹是彩色的。

- **按住鼠标左键拖拽**，在空白处画出平台、桥梁、斜坡或墙壁；松开笔，墨迹就会变成实体。
- 每一笔都会消耗**墨水**。墨水会缓慢恢复；双脚落地、站定不动时恢复得更快。
- 画出的墨迹会随时间**褪色消失**。在雾之谷里，褪色速度会快得多。
- 找到发光的**墨露**补充墨水，点亮**纸灯笼**记录重生点并回满墨，最后走到**画框**前，让这一章的颜色回来。
- 在星屑高塔，风会把你推下悬崖；靠近自己画的墨墙，风就会绕行。

没有失败惩罚。掉下去，回到灯笼处，再画一次就好。

## 章节

| 章节 | 主题 | 新元素 |
| --- | --- | --- |
| 一 · 白纸原野 | 颜色睡着的地方 | 基础画桥、墨水与褪色 |
| 二 · 断崖回廊 | 回声替你走路 | 垂直攀爬、长距离斜桥 |
| 三 · 雾之谷 | 雾会吃掉墨，也会吃掉记忆 | 加速褪色的雾、色彩之种 |
| 四 · 星屑高塔 | 风从不记得方向 | 风场、墨墙挡风、必须作画的高空缺口 |
| 五 · 归色之庭 | 最后一页，留给你 | 无限墨水、终章与明信片 |

## 操作

| 输入 | 动作 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 移动 |
| `空格` / `W` / `↑` | 跳跃（长按跳得更高） |
| 鼠标左键拖拽 | 作画 |
| `Esc` | 暂停 / 继续 |
| `R` | 重画本章 |
| `M` | 静音 |

## 技术

- 纯 HTML / CSS / JavaScript，无框架、无构建步骤。
- Canvas 2D 绘制全部山水、人物、粒子与 UI 画面。
- WebAudio 实时生成环境音乐、五声音阶拨弦与音效，没有音频文件。
- 所有视觉与声音均为程序化生成，**未使用任何外部图片或音频素材**。
- 画面与氛围参考了《Gris》《The Unfinished Swan》《Concrete Genie》《Chicory: A Colorful Tale》等作品对「色彩叙事」的处理，但未复用任何素材或关卡。

## 本地运行

直接打开：

```text
index.html
```

或启动一个本地静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 备注

- 游戏进度保存在浏览器 `localStorage` 中，清除站点数据会重置进度。
- 通关后可以「保存这幅画」，把最后一幕导出成一张带标题与统计的明信片。
- 按 `M` 或右上角音符可以静音；浏览器需要一次点击才会开始播放声音。
